// FREQUENTLY ASKED QUESTIONS (よくあるご質問)

Q1. 決済完了後、APIキーやライセンスはどのように発行されますか？
完全自動化されています。Stripeでの決済が正常に完了した瞬間に、システムがバックグラウンドで連動し、登録されたエンドポイントおよびコンソールに対して瞬時にソブリン・ライセンスと認証キーが発行・有効化されます。人間のスタッフを介さないためタイムラグは一切ありません。
Q2. HTTP 402ナノセトルトメントとは何ですか？どのようなメリットがありますか？
HTTP 402 (Payment Required) プロトコルをベースにした、マイクロ秒単位での極小額自動決済システムです。従来の月額固定費にとどまらず、APIの利用実績やデータ通信量に応じた最適かつ無駄のないナノ単位の経済活動を自律的に完結させることができます。
Q3. プランのアップグレードやダウンスケールはいつでも可能ですか？
はい、中枢コンソールよりいつでもリアルタイムに変更可能です。変更に伴う権限の移行やネットワークの再同期も自動ミューテーション制御によって一瞬で処理されます。
